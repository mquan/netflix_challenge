The separate source adapter now prepares and streams the full qualifying
operators for either original scalar or learned-context arm. It reuses the
original known-only source preparation and all ten eligible ridge1000 weight
vectors, binds the actual qualifying operator hashes from the complete CPU
manifest, and preserves all2817131 query rows and714/864 feature columns.
The bounded binary stream includes all ten matching baseline vectors.

Query-specific source files are added to both the source declaration and the
authenticated record set. The original known metadata digest and exact weight
bytes remain explicit links for the future selected-study owner to compare.
The dedicated Torch-capable producer performs no tree fitting or selection;
the model inference receiver remains separate. Full source identities and
operator/weight bits must survive the complete stream.

isolated children, exercise both full feature widths with actual ten-system
ridge solves, stream103 synthetic qualifying rows through the bounded receiver,

source file verifies matching declaration/record-set expansion. Pending CPU
proofs, changed weight bits, altered qualifying row counts and changed query
code are rejected. No full production source or score is admitted.
