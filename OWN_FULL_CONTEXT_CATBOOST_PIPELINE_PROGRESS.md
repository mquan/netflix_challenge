# Isolated source to complete tree-study pipeline

The connection component now launches an original-scope producer under an
already authorized dedicated scientific root. The producer waits for byteG
on stdin. The root captures its actual lifetime and group, authenticates the
full immutable source closure and requires an external authorization matching
the exact root, producer, command, mode, arm, manifest and stream. Only then
is the source released to write the bounded pipe.

The same root drains the complete raw stream before polling the actual child
exit. It publishes the exclusive zero-exit receipt only after waitpid confirms
success and reauthenticates original source and authorization bytes. Complete
fitting or saved-model replay follows that gate. Separate pipeline receipts
bind the actual scientific output, source-role admission and exit proofs.
The tree process remains Torch-free while its separate producer may import it.

If a source role is still live when authorization or execution fails, the
component retains its actual handles and channels and calls the external
whole-family preservation hook. It provides no production kill, retry, resume,
lane-release, standalone CLI or queue. Partial/full namespaces are preserved.
The external owned controller, watchdog and family resource guard are still
required; this component alone cannot authorize a production study.
