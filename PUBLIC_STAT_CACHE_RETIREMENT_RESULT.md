# Obsolete public-bank statistic caches retired

Under the user's existing authorization to remove public-bank results, five
obsolete public-derived `.stats.npz.zst` caches were discarded. Each original
configuration names the exact public output prefix and pinned public manifest,
with536 downloaded-public input paths. These are cached statistics for old
public-bank blends, not freshly trained own models or checkpoints.

The exact five names, original SHA256/identity and preserved metadata hashes
were fsynced before any unlink. All were untracked, unflagged, regular
single-link files without open users. None shared an inode with any file in
the11 current scientific source closures. Original inputs/result/manifests
remain, and all protected scientific proof hashes match before and after.
No process, model, checkpoint, prediction, training dataset or source changed.

Logical bytes discarded: 2,692,475,701. Measured free-space
gain: 2.508GiB. Free disk after
cleanup was about22.91GiB, providing room for pending native outputs and
weekend query returns above the existing18.75GiB floor. This was intentional
public-cache disposal, not lossless archival.

A separate read-only verifier confirms the exact five paths are absent and
replays all11 protected proof hashes and12 preserved metadata/source hashes.
It cannot rehash bytes that have already been discarded; the original hashes
and identities remain in the pre-deletion journal. No scientific score is
claimed by this cleanup.
