# Downloaded public qualifying-prediction cache retirement

On November21,2026, the existing authorization to remove downloaded public-bank
results was applied to236 verified public prediction inode groups and all382
of their hardlink aliases. The236 original arrays total2,659,401,872logical
bytes. Measured free-space gain was2,659,414,016bytes (2.47677GiB), leaving
about22.29GiB free immediately after independent verification.

Every selected inode had an actual alias in the original public qualifying
download manifest, matching its recorded SHA256 and the original download
index's MD5/size. The index SHA256 is fixed to the same historical value used
by the earlier committed downloaded-reference retirement. The full float32
prediction-vector header, every hardlink, closed-file status, regular paths,
tracking status and attributes were checked. All aliases were inside four
explicit old public-cache roots. All current own artifact inodes and13 own
scientific metadata/proof closures were excluded.

The complete pre-deletion journal was committed and pushed before execution.
All236 arrays were rehashed/reclassified before removal; every unlink was
journaled with directory synchronization. Seven anchored inode groups with an
index mismatch were retained. Files without an actual download-manifest alias
were never selected. Own models, checkpoints, predictions, data, archives and
working state were retained; no scientific process was signalled.

This is intentional disposal of downloaded public predictions, not lossless
archival. Original manifests, catalog and pre-deletion hashes remain. The
separate verifier checks absence, complete accounting, original provenance
and unchanged protected proof hashes; it cannot rehash deleted bytes. No
qualifying outcomes were read and no score is claimed by this work.

Eight private eligibility tests cover full valid arrays/hardlinks, own-inode
and tracked-file exclusion, unknown/nonpublic hardlinks, provenance mutation,
changed numerical bytes, incorrect schema, symlinks and replacement catalogs.
The bounded journal and fixed historical pin also passed independent read-only
review before removal.
