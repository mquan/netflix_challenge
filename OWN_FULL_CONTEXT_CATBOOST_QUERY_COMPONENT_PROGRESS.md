# Producer lifecycle and full qualifying block components

A parent-observed lifecycle helper now captures an actual waiting producer
child and its source/stream binding. Polling returns immediately while it is
live. Only the same actual parent observing its reaped zero exit can publish
the exclusive producer receipt. EOF, nonzero exit, changed lifetime, wrong
handle, changed source or changed owner cannot publish success. The helper
does not spawn, terminate, resume or release any scientific role or lane.

The bounded query receiver uses the existing authenticated binary format and
retains only an8192-row raw block and its ten eligible ridge baseline vectors.
Every row, feature, baseline, footer and EOF is checked. External inference
callbacks receive immutable original arrays; mutation, truncation and trailing
bytes are rejected. Callback results remain provisional until full stream
verification, parent-observed producer success and independent bag replay.

The saved-model inference component authenticates and opens all five folds,
including every positive model and all zero seed slots. Each block installs
only the matching full-eligible ridge baseline as the last float32 feature.
It accumulates float64 seed predictions divided by three in original order,
adds the matching float64 baseline, clips and casts each fold to float32,
then accumulates the five float32 fold vectors in float64 and divides by five.
No fitting, source admission, selection, prediction publication or outcome
audit is authorized by these helpers.

The61-check combined tree suite passed after adding the real child lifecycle
and full-width query receiver tests. Two additional focused inference checks
passed using five actual small saved/reloaded CPU CatBoost models and an8192-
row all-zero-slot case. Source/ownership/row fixtures remain synthetic. These
checks do not establish full production memory peaks, completion or a score.
