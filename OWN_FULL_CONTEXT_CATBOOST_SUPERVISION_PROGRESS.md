# Whole-family supervision component

The original numerical-family guard now connects the fixed16GiB complete
family limit and24GiB aggregate physical/RSS limits to actual stop/continue
operations. It keeps the unchanged native observer scope, exact original
scientific baseline, compressor/swap limits, disk floor and complete remaining
output reservation. Source/owner/watchdog or accounting failures stop the same
original group from inside its current frame. Readmission requires three
consecutive independent full16GiB reservations, ten seconds between samples,
and the same live original root, owner and watchdog before SIGCONT.

The watchdog retains inherited lane descriptors while any captured original
root or source role remains live. Owner loss, an early release request or
uncertain metadata preserves known groups. Previously captured live families
remain tracked even when a current pointer disappears. A surviving source
cannot resume automatically after root loss. No CLI, queue, retry, termination,
resource-limit relaxation or production admission is provided by this module.
The external full owner and phase/role bootstrap still need integration.

All76 combined tree component checks passed. The new checks include actual
SIGSTOP/CONT of a dedicated helper group, verifying the same PID, Python object
identity, local batch state and RNG sequence after resumption. Resource samples
are synthetic in this frame test; it does not test a production optimizer or
establish real production headroom. Another actual process test confirms an
inherited POSIX lane lock remains unavailable while its stopped original helper
is live and becomes available after that helper is terminal. Policy fixtures
reject a replaced baseline or undersized remaining-output declaration, require
three consecutive samples after a failure, and retain a previously known live
family on missing/malformed current metadata. Only private test helpers are
released/terminated for fixture cleanup; live scientific jobs are unchanged.

whole-run source review and actual production admission; both full tree studies
