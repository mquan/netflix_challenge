# Owned complete selected-tree qualifying pair, version 1

The original goal remains primary RMSE strictly below 0.85725 on both complete
community-recovered qualifying groups, using freshly trained own models and
known-only local fitting and selection. These adaptive recovered audits are not
official or untouched Test scores. This controller produces a prediction pair;
its completion does not establish the goal or a new score.

Both full scalar and latent CatBoost known studies, actual saved-model and full
raw/ridge/OOF replays, separate canonical known CV proofs, and their complete
known-only selection must finish under the original known-tree owner first.
The selection gate rechecks both complete known scores and retains the scalar
tie rule at tolerance 1e-12. It authenticates all nine original phase/resource
receipts, model and vector closures, source runtime and unchanged baseline.
No qualifying outcomes influence this choice. If the original own17 primary
already meets the strict target on both groups, the original full canonical
audit and known-owner not-needed decision must both verify before skipping.

The four ordered phases are prepare, infer, replay and admit. Preparation runs
in a dedicated source-capable root, re-solves the ten original eligible ridge
systems and writes metadata matching the exact selected full known arm. That
root must terminate before the separate inference root starts. Inference and
replay roots stay Torch-free. Each launches its own fresh original-scope source
child, captures its actual lifetime while waiting at byte G, and releases it
only after an immutable external authorization binds the complete request.
The source verifies that authorization before importing Torch or loading full
data, then reproduces the exact prepared metadata before streaming.

Every original qualifying row (2,817,131), known row (1,128,164), full selected
feature/context column, five folds and fifteen positive/zero seed slots remain
required. Blocks are at most 8,192 rows. The original arithmetic is an ordered
float64 sum of each positive seed prediction divided by three, plus the eligible
baseline, clipped to [1.05,4.95] and rounded to float32 per fold; then an ordered
float64 sum of all five float32 folds divided by five, clipped and rounded to
float32. Zero slots remain in the original denominators. The matched known
vector is the exact selected tree OOF vector, exported bit-for-bit.

Complete bytes, footer and EOF do not authorize prediction publication. The
actual parent must reap its own producer at exit code zero with unchanged
source/authorization bindings. Logical metadata admission hashes and saved
metadata-file hashes remain distinct. Replay uses a fresh full source, ten
independent ridge solves, every actual saved model, separate direct native
prediction/rounding loops and every known/fold/bag bit. It does not call the
production block prediction routine. No model is fitted by these four phases.

Final checks authenticate both actual source/root lifetimes, original source
requests, external authorizations, admissions, parent-observed exit receipts,
full stream/model/vector proofs and all prediction file hashes. The pair-check
proof remains pending the external owner's final completion, which binds all
four phase receipts and all four observed-resource proofs after every captured
scientific role is terminal. A downstream own18 provider must require that
complete owned proof, rather than accepting a standalone component receipt.
