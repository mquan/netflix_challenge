# Training-day context in the compact ensemble

`src/moonshot_session_meta.cpp` computes six features for each probe row using
only that user's training ratings: log count on the same day, a shrunk
same-day mean deviation from the user's mean, shrunk fractions of ratings 1
and 5, same-day rating spread, and gap to the nearest training rating day.
521,083 of 1,408,395 probe rows have at least one same-day training rating.
`tests/test_moonshot_session_meta.py` verifies that changing probe labels
leaves all six output columns byte-identical.

C10 adds these six support columns to C9's unchanged seventeen prediction
columns, four existing support columns, extra context features and tree
settings. All common input hashes match C9. Development CV falls from
**0.8750626363 to 0.8749217647**, a **0.0001408716** gain. All five held-out
user folds improve by 0.00002926–0.00024819. Independent float32 scoring
gives 0.8749217647; saved out-of-fold SHA-256:
`189cbe747233fd31e149f000094de30645c000f9a6a9b5b2de3d75fb33a210f6`.

The feature-generation manifest is
`experiments/SESSION-C9-training-day-meta.json`; the matched blend report
with all six input hashes is `experiments/SESSION-C10-blend.json`. C10 was
the best reproducible local development result at that checkpoint,
**0.0001123558** above
historical R5's 0.8748094089 and **0.0199217647** above the 0.855 target.
This is still probe-guided development selection, not an independent test.

## Same-day joint residuals and fixed average

The next run adds two training-only features: the shrunk mean and spread of
the same-day residuals from a frozen J3 joint model. It keeps C10's first six
feature files byte-identical and adds only the two new columns. The generator
manifest hashes both the dataset and frozen model. The probe-label-isolation
test passes for all eight features.

C11 scores **0.8748606495**, improving C10 by 0.0000611151 overall. Four
folds improve; fold 2 worsens by 0.00008043. Independent float32 scoring
gives 0.8748606495. The saved C11 prediction SHA-256 is
`c4e9b96b8e15408d596724c9ba6e4596468b8201342be5d40f6fc2300e95459a`.
The feature run and matched blend reports are
`experiments/SESSION-C10-joint-residual-meta.json` and
`experiments/SESSION-C11-residual-blend.json`.

A **fixed equal average** of C10 and C11's saved out-of-fold columns scores
**0.8747780516** (C12), which is 0.0000313573 below historical R5's
0.8748094089 and 0.0197780516 above the 0.855 target. The saved float32
column independently scores 0.8747780515; its SHA-256 is
`93129d524dcd2749d7fc7ccdaf32ee03277f7b2a942035805a0c3dd07eed6940`.
All input hashes, method and per-fold scores are in
`experiments/SESSION-C12-fixed-half.json`, generated by
`scripts/fixed_average.py`. C12 beats R5 in three folds and trails in two;
the overall margin is small and both results were selected using probe
feedback. A fitted second-stage weight screen is archived separately at
`experiments/SESSION-C10-C11-combination.json` but is not the primary result,
because its training predictions can indirectly depend on the held fold's
labels through the first-stage tree fits.

A C9-to-C12 slice check shows improvement with no same-day training rating
(0.9001916 to 0.9000367 RMSE) and a larger improvement with one to five
same-day training ratings (0.8395809 to 0.8389431). The gains across all
three activity slices are recorded in `experiments/SESSION-C12-slices.json`.
The no-same-day gain means the result should be interpreted as the whole
tree-blend change, including the nearest-day feature and feature sampling,
not solely the effect of same-day residuals.
