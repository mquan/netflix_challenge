## Root and source roles

The external owner first acquires the two original primary/GPU lane open-file
descriptions, inherited by its independent watchdog. Admit a dedicated
scientific root only after three stable original-policy reservations. Its
bootstrap writes the actual PID/start/command/group capture before dispatch.
The fitting, replay, canonical and selection roots must remain Torch-free;
preparation and the isolated source producer may import Torch.

For fit/replay, use the implemented pipeline component. Its child command must
remain in the original observer scope, inherit the root's process group and
wait for byteG on stdin. The source worker must publish its actual bootstrap
capture before waiting. The root's role authorization callback must validate
its complete original phase gate and the exact pipeline request, register the
source capture for both owner and watchdog, publish exclusive authorization,
and only then permit release. A source must validate root, owner, watchdog,
phase/source bindings and authorization before importing its numerical adapter.
Fresh `producer_v2.prepare` metadata/weight bytes must equal the original saved
arm preparation before `producer_v2.send` writes the binary stream. Diagnostic
text must go to stderr; stdout is exclusively the binary handoff.

Use `supervision.Control` for the original complete family and `Guard` inside
both scientific roles. Its role provider must merge the immutable root capture,
registered source capture and early source bootstrap capture; a missing or
malformed pointer must not discard a previously captured live lifetime. Source
failure preservation must stop the entire original group before returning or
closing a still-live role's channels. The external owner must not advance or
release lanes until both root and every captured source are actually terminal.

If the root disappears while a source survives, the watchdog stops that group,
keeps both lane descriptors and never resumes or recreates it automatically.
If accounting, metadata or sources are uncertain, retain existing captures,
RAM, descriptors and stopped frames. Resume only the same original live root
and group after three successful independent full reservations and unchanged
original authorization/baseline. No original observer scope expansion is needed.
