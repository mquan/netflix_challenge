# Complete independent weekend return admission

This is a local admission stage for all67 named epoch/terminal pairs of the
three already declared fresh original weekend producers. It trains no model,
reads no recovered target and selects no epoch by score. Each producer must
complete both original phases and all original outputs before admission.
An unavailable or partial producer is never represented as complete.

There are separate, immutable per-producer report, import and queue
directories under `upstream-remote-weekend-return` and
`upstream-remote-weekend-return-queue`. Existing partial returns are retained;
there is no automatic retry or overwrite. The coordinator freezes the exact
remote execution commit only after a complete transfer manifest exists.

The intake independently binds the original source pin and assignment plan,
controller, unchanged command/environment, full epoch traces and native
receipt. Required outputs are every full native holdout/qualifying epoch and
terminal query, both complete training-prediction arrays, and both original
RBM item-factor arrays (including the400pf factorization). Each part and
every decoded member must retain its original size/SHA. No path traversal,
symlink, duplicate, unlisted or missing archive member is admitted. The full
gzip stream is decoded, including its CRC/trailer. Every native numerical
payload, including large side arrays, is checked for exact float32 shape and
finiteness while streaming.

All complete native query arrays, compact paired exports, original source,
binaries and metadata are materialized. Large training/factor side arrays
remain losslessly preserved in the byte-verified original remote draft
release archives; their entire local stream is checked before discarding
the streaming buffer. No original remote output is deleted. Local storage
reserves40MiB per named pair plus128MiB before import, above the unchanged
18.75GiB floor. All materialized bytes remain bound to original expectations.

A separate verifier rehashes every retained file and all original local
source/data/split expectations. It recomputes the complete canonical known
projection and original row-map SHA, scans all98,720,013 training identities
to prove the full1,760,494-row native holdout is absent, and confirms
qualifying fitting targets are zero. Every1,128,164-row known compact vector
and every2,817,131-row qualifying compact vector must match the full native
query bits; terminal and final-epoch aliases must match on both queries.
Full clipped pair hashes are recorded for subsequent score-independent
alias removal. No new fit, ensemble or score is claimed by admission.

The waiting queues start heavy work only after the current own15 assembly
and separate canonical verification finish, without consulting its outcomes.
They require a complete pinned remote transfer, the actual primary lane,
three stable admission samples below4.5GiB compressor,2GiB worker reserve,
24GiB total research physical/RSS,5GiB continuous compressor and128MiB swap
growth from the same first scientific baseline across both phases. No GPU
lock is taken. A dedicated bootstrap cannot execute without its live owner
and already-running watchdog. Guard or owner loss preserves the same actual
worker process in RAM; no restart, reduced recipe or source change is allowed.

All three producer identities are predeclared; actual execution still depends
on complete original training and transfer. These returns will supply a
later, separately declared complete-input model iteration. They do not change
any already frozen391/trajectory study or imply that the10% goal is achieved.
