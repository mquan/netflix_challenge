# Selected tree query pipeline connection

The new pipeline component connects either complete selected-tree inference or
independent replay to a fresh isolated source in an already authorized scientific
process group. It authenticates the completed known-only selection, matched query
metadata, original source closure, and exact replay predecessor before spawning.
The source waits for byte G until the actual parent captures its lifetime and an
external owner writes an immutable authorization matching the complete request.

The parent drains the bounded stream in its existing frame and independently
reaps its actual child. Complete bytes and EOF alone do not authorize publication:
only a successful source exit, unchanged source and authorization identities, and
an exact logical stream-admission hash release the component publication gate.
Metadata file hashes remain distinct from logical metadata hashes. Separate
control paths avoid creating the inference output directory before assembly.
An error with a still-live source retains its original handle and pipe channels
and invokes the caller's family-preservation hook. There is no retry or kill path.

All 104 combined tree component checks passed in 78.460 seconds. Four new checks
use actual dedicated process groups, isolated Torch source processes, pipes and
parent-observed exits. They cover fresh inference/replay lifetimes, nonzero exit
after complete EOF, changed authorization, and missing authorization with a live
preserved source. Their scientific inference/replay bodies, selection and data
admission are synthetic fixtures. Separate existing checks exercise actual small
saved CatBoost models, independent ridge solves and every exported prediction bit.
These checks establish no production score, data admission or resource peak.

This is a component, without a standalone supervisor or production launch. The
remaining owned qualifying controller must supply the original lanes, watchdog,
full-family resource gate, source bootstrap and final pair admission. Full real
qualifying inference/replay and own18 calibration/audits remain required. The
live known-tree owner and its 364-file source snapshot remain unchanged.
